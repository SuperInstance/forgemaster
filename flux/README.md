# Flux

The Flux language ecosystem — compilers, runtimes, ISAs, frontends, and tooling.

Flux is a constraint-native language designed for formal verification, GPU programming, and embedded systems. This directory contains ~47 projects spanning:

- **Compilers & VMs:** `flux-compiler`, `flux-vm`, `flux-vm-v3`, `flux-compiler-workspace`
- **ISA targets:** `flux-isa`, `flux-isa-c`, `flux-isa-edge`, `flux-isa-mini`, `flux-isa-std`, `flux-isa-thor`
- **Language frontends:** `flux-algol`, `flux-chapel`, `flux-cobol`, `flux-fortran`, `flux-pli`, `flux-snobol`
- **GPU & CUDA:** `flux-cuda`, `flux-gpu`, `flux-hardware`
- **Libraries & SDKs:** `flux-lib-py`, `flux-sdk-python`, `flux-ffi`
- **Analysis & Verification:** `flux-check`, `flux-check-js`, `flux-check-py`, `flux-verify-api`, `flux-provenance`
- **Domain-specific:** `flux-genome`, `flux-hdc`, `flux-hyperbolic`, `flux-tensor-midi`, `flux-rpg`
- **Infrastructure:** `flux-deploy`, `flux-docs`, `flux-site`, `flux-integration-tests`, `flux-contracts`
