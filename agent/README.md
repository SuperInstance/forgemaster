# Agent

Autonomous agent frameworks and shells.

- `agent-field` — Field agent runtime
- `fleet-agent` — Fleet-coordinated agent
- `python-agent-shell` — Python-based agent shell
- `smart-agent-shell` — Advanced agent shell
- `mud-agent` — MUD-style agent interface
- `luciddreamer-agent` — LucidDreamer integration agent
- `zeroclaw-agent` — ZeroClaw agent implementation
